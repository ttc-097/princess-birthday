NISHU Birthday Website — Setup
1. Keep index.html, style.css, script.js together.
2. Put 3 photos in assets/photos named memory01.jpg, memory02.jpg, memory03.jpg.
3. Put your video in assets/video named birthday-message.mp4.
4. Optional: put music in assets/music named bg-music.mp3.
5. Double-click index.html to test.
6. Edit memories/questions/clues in script.js to personalize.
7. For online sharing, upload the whole folder to a static host such as GitHub Pages, Netlify, or Cloudflare Pages.
